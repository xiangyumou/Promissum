# Promissum - Product Requirements Document (PRD)

## 📋 Product Overview

### Project Name
**Promissum** - 基于时间锁加密技术（Timelock Encryption）和 drand 去中心化随机信标网络的内容保护应用

### Product Positioning
Promissum 是一个**统一的时间锁加密平台**，集成了前端界面和加密服务。系统基于 BLS12-381 曲线的身份基加密（IBE）和 drand 去中心化随机性网络，允许用户对文本或图片内容进行加密，并设定一个未来的解锁时间。在设定的时间到达之前，任何人（包括用户自己）都无法解密查看内容，从而实现真正的"强制自律"功能。

### Architecture
```
前端 UI (Next.js)
    ↓
API Routes (同进程集成)
    ↓
内置加密服务 (tlock-js)
    ↓
drand 网络
```

### 核心价值主张
- **强制时间锁定**：基于密码学的时间锁，而非简单的软件限制，无法提前解密
- **统一架构**：集成加密服务，简化部署和维护
- **多设备同步**：设备间实时状态同步，支持多端无缝使用
- **功能完备**：包含仪表盘、高级筛选、实时更新等完整应用特性
- **灵活扩展**：支持延长锁定时间（多层加密）

## 🎯 目标用户

### 主要用户群体
1. **自律提升者**：希望通过"强制锁定"机制来提升自控力的用户
2. **隐私保护者**：需要对敏感信息进行时间限制访问的用户

- 💌 给未来的自己写信，设定未来某天才能查看
- 🎁 准备惊喜礼物信息，在特定日期自动揭晓
- 📝 锁定敏感文档，仅在需要时才能访问
- 🔐 存储紧急备份密码，设定冷却期防止冲动操作

## 🚀 核心功能

### 1. 内容加密与时间锁定

#### 功能描述
用户可以创建加密项目，支持两种内容类型：
- **文本内容**：直接输入文字信息
- **图片内容**：上传图片文件（PNG, JPG, GIF, WebP），支持粘贴上传

#### 时间设定方式

##### 方式一：持续时长模式 (Duration Mode)
- 预设快捷按钮：`1分钟`、`10分钟`、`1小时`、`6小时`、`1天`
- 支持多次点击累加时长
- 自定义输入框：可输入任意分钟数
- 重置按钮：清空当前设定

##### 方式二：绝对时间模式 (Absolute Time Mode)
- 直接指定解锁时间点（格式可配置）
- 系统验证输入时间必须在未来
- 自动显示与当前时间的倒计时

#### 界面展示
- **预览解锁时间**：动态显示解锁的具体日期时间
- **剩余时间显示**：倒计时格式

#### 技术实现要点
- 内置加密服务处理加密逻辑 (`tlock-js` + `drand`)
- **多层加密** (layer_count)：支持对已加密内容再次加密
- **实时同步**：加密数据通过 SQLite 跨设备共享

---

### 1.5 多设备同步与实时更新

#### 功能描述
支持多设备同时使用，所有状态实时同步。

#### 特性
- **状态同步**：设置、项目列表、缓存状态同步
- **实时同步**：基于 React Query 智能轮询 (Smart Polling) 的近实时更新
- **冲突处理**：最后写入优先（LWW）策略

---

### 2. 加密项目管理

#### 侧边栏列表 (Sidebar)
- **排序与筛选**：
  - 支持按创建时间、解锁时间排序
  - 支持按状态（锁定/解锁）、类型（文本/图片）筛选
  - 时间范围筛选：今日、本周、本月、自定义范围
  - 筛选预设：保存和加载自定义筛选配置
  - 快速筛选：即将解锁、长期锁定、最近创建
  - 模糊搜索：智能匹配项目名称和内容
- **项目卡片信息**：
  - 内容类型图标：📝 文本 / 🖼️ 图片
  - 项目名称：支持自定义标题
  - 锁定状态：实时倒计时或 Unlocked 状态
  - 隐私模式：支持模糊显示敏感信息
  - 倒计时视觉：渐变色彩、脉冲动画

#### 项目详情视图 (ContentView)
- **顶部信息栏**：
  - 内容类型 + 名称
  - 多层加密标识：`×N`
  - 操作栏：删除、延长锁定
  - 会话指示：显示其他设备正在查看
- **锁定状态显示**：
  - 🔒 动态倒计时，每秒刷新
  - Unlocks at 具体时间显示
  - 倒计时视觉增强：渐变色彩、脉冲动画
- **解锁状态显示**：
  - **文本内容**：显示明文，支持一键复制
  - **图片内容**：LightBox 预览，支持缩放、下载
  - **解锁特效**：彩带庆祝动画和音效

### 3. Dashboard 仪表盘

#### 功能描述
提供全局数据的可视化概览，帮助用户了解使用情况。

#### 展示指标
- **系统总览**：总项目数、已加密、已解锁数量
- **类型分布**：文本 vs 图片比例
- **平均锁定时间**：用户的平均自律时长
- **状态分布**：锁定/解锁比例图表

### 4. 设置与个性化 (Settings)

#### 功能描述
全方位的应用配置中心，支持实时保存。

#### 配置项
1. **默认行为**：默认锁定时长、确认对话框开关、自动刷新间隔
2. **外观定制**：
   - 主题切换：浅色 / 深色 / 系统跟随
   - 主题色定制：自定义主色、背景色等 CSS 变量
   - 语言切换：English / 中文
3. **隐私安全**：
   - 隐私模式：默认模糊列表内容
   - 自动隐私模式：无操作一段时间后自动进入隐私模式
   - 紧急按钮 (Panic Button)：快捷键跳转指定 URL
   - 缓存策略：自定义解密内容在本地的缓存时间 (TTL)
4. **数据管理**：
   - 导出数据：导出已解锁内容为 JSON/Markdown
   - 清除数据：重置所有设置或缓存

## 🔐 安全性与隐私

### 数据库
- **SQLite**：轻量级文件数据库，零配置
- **Drizzle ORM**：类型安全的轻量级 ORM

### 加密流程
1. 前端通过 API Routes 提交内容
2. 内置加密服务使用 `tlock-js` 加密
3. 加密数据 (Ciphertext) 存入 SQLite
4. 到达时间后，服务解密并返回明文

### 前端安全
- **敏感数据缓存**：用户通过 TTL 设置控制缓存时间
